About this project

Each calculator combines tree size, species density, site access difficulty, and regional labor rates into a transparent estimated price range — not a fixed number — since real-world quotes vary with root complexity, crew time, and local conditions.

Built solo as a self-contained static site: no backend, no database, no build step.
