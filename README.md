# 🌲 Tree Removal Cost Calculator

Free, instant cost estimators for tree removal, stump grinding, and tree trimming — no sign-up required. Built to help homeowners get a realistic price range before hiring an arborist.

🔗 **Live site:** [treeremovalcostcalculator.me](https://treeremovalcostcalculator.me)

## 🧮 Tools

- [Tree Removal Cost Calculator](https://treeremovalcostcalculator.me) — estimate cost by height, trunk diameter (DBH), species, and ZIP code
- [Stump Removal Cost Calculator](https://treeremovalcostcalculator.me/tree-calculators/stump-removal-cost-calculator) — grinding vs. full removal, priced by diameter and wood type
- [Tree Trimming Cost Calculator](https://treeremovalcostcalculator.me/tree-calculators/tree-trimming-cost-calculator) — pruning and trimming cost by tree size and condition

## ✨ Features

- ISA-standard measurement conventions (DBH, height brackets)
- ZIP-code-adjusted regional pricing
- Instant, itemized cost breakdown — no email or sign-up required
- Mobile-responsive, accessible form design
- FAQ sections with Schema.org structured data for rich search results

## 🛠️ Built With

- HTML / CSS / JavaScript (vanilla, no framework dependencies)

## 📖 About

This project estimates real-world tree service costs using publicly available arborist pricing data, adjusted for tree size, species, site access, and regional labor rates. It's built to give homeowners a transparent starting point before requesting quotes — not a replacement for a licensed arborist's on-site assessment.
